# 50 animated background ideas

The ideas start with familiar styles from popular sites and get more unusual
further down. These are full-screen hero and page backgrounds, separate from the
studio backdrops in [background-ideas.md](background-ideas.md).

## Rule: every background ships with a UI layer

No background is shown bare. Each preview fills the screen with real interface
pieces, so the background is judged behind content, as it would be used.

- At least one **navigation element**: a top bar, side rail, bottom dock or
  floating pill.
- At least one **call to action**: buttons, a form, or a search field.
- Content placed so the screen is **filled**, not one centred word. Use the
  layout listed for each idea, and vary layouts between neighbouring
  backgrounds.
- Text stays readable over the moving background, using a scrim, a glass panel
  or contrast-checked colours.
- Reference build: `FluidGradient` + `FluidLogin` (a white side panel with a
  form, a top nav over the gradient, and the headline at the bottom right).

Layout key: **Top nav** = horizontal bar · **Side rail** = vertical icon/menu
strip · **Split** = solid panel beside the background · **Dock** = bottom bar ·
**Floating** = pill or card over the background · **Corners** = UI pinned to the
corners.
