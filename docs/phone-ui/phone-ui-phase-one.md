# Phone UI: Phase One

The easy builds from the [48 phone UI ideas](phone-ui-ideas.md). Every build is
a multi-screen click-through prototype: a bottom tab bar or in-app navigation,
every row and button leads to a real screen, and a `startScreen` select jumps
to any page (as Food Tracker App does).

## Suggested first three

Banking home (9), Onboarding flow (48) and Messenger (33). Each has a natural
page flow, and together they cover the three typical navigation shapes: tab
bar, linear flow and list-to-detail.
