# Distribution

[Back to all chart types](../README.md)

- [Histogram](histogram.md) — Counts of values in equal-width ranges (bins).
- [Box Plot](box-plot.md) — Median, quartiles, whiskers and outliers.
- [Violin Plot](violin.md) — A box plot with a mirrored density shape on each side.
- [Density / Ridgeline Plot](ridgeline.md) — Smoothed distributions stacked with slight overlap.
- [Strip / Swarm Plot](strip-swarm.md) — Every data point drawn, spread so none overlap.
