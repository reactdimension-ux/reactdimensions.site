# Other

[Back to all chart types](../README.md)

- [Waterfall Chart](waterfall.md) — Floating bars showing how additions and subtractions build to a total.
- [Pareto Chart](pareto.md) — Descending bars with a cumulative percentage line.
- [Slope Chart](slope.md) — Two points per item joined by a line (before vs after).
- [Population Pyramid](population-pyramid.md) — Two bar sets mirrored around a centre axis.
- [Parallel Coordinates](parallel-coordinates.md) — One vertical axis per variable; each item is a polyline.
- [Word Cloud](word-cloud.md) — Words sized by frequency.
