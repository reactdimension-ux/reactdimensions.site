# Pareto Chart

**Group:** Other

## What it shows
Descending bars with a cumulative percentage line.

## Best for
Finding the vital few causes (80/20).

## Avoid when
Categories have no ranking meaning.

## Data it needs
Category + count.

## Variants
With 80% reference line.

## Suggested props (React Dimensions component)
`data, showCumulative, threshold, colors`

Every option should be a prop with a default, with `prefers-reduced-motion` respected and an accessible text summary (`role="img"` with an `aria-label`, or a visually hidden data table).
