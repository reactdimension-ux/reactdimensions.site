# Comparing categories

[Back to all chart types](../README.md)

- [Bar / Column Chart](bar.md) — One bar per category, length proportional to value.
- [Lollipop Chart](lollipop.md) — A bar reduced to a thin stem with a dot at the end.
- [Dot Plot (Cleveland)](dot-plot.md) — One dot per category on a shared axis; two dots per row show before/after.
- [Bullet Chart](bullet.md) — One value drawn as a bar against a target marker and qualitative ranges.
- [Radar / Spider Chart](radar.md) — Several metrics for one or more items on spokes around a centre.
