# Change over time

[Back to all chart types](../README.md)

- [Line Chart](line.md) — Points connected in order, usually along a time axis.
- [Area / Stacked Area Chart](area.md) — A line chart with the space under it filled.
- [Step Chart](step.md) — A line that holds its value and jumps at each change.
- [Sparkline](sparkline.md) — A tiny line or bar trend with no axes or labels.
- [Candlestick / OHLC Chart](candlestick.md) — Open, high, low and close for each period as a body with wicks.
- [Gantt Chart](gantt.md) — Tasks as bars along a timeline with start, end and dependencies.
- [Streamgraph](streamgraph.md) — A stacked area centred on a wiggling baseline so layers flow.
