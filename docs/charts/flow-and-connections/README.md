# Flow and connections

[Back to all chart types](../README.md)

- [Sankey Diagram](sankey.md) — Bands between nodes, with width proportional to flow.
- [Alluvial Diagram](alluvial.md) — A Sankey that follows groups across several stages or points in time.
- [Chord Diagram](chord.md) — Groups on a circle joined by ribbons sized by flow.
- [Network / Graph](network.md) — Nodes and the links between them.
- [Funnel Chart](funnel.md) — Stages narrowing in width as items drop off.
- [Tree / Dendrogram / Flowchart](tree.md) — Boxes or nodes joined to show hierarchy or process.
